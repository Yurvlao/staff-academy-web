# STAFF Академия — вход для ассистентов

Рабочий репозиторий: Yurvlao/staff-academy-web, ветка main.

До работы прочитайте канонические [инструкции ролей и протокол передачи](https://github.com/Yurvlao/traineesimulator/blob/main/AGENTS.md) и [журнал SA с актуальным run state](https://github.com/Yurvlao/traineesimulator/blob/main/журнал%20SA.md).

Оба документа находятся в приватном репозитории и требуют доступа. Не копируйте журнал запросов в публичный репозиторий. Если доступа нет, прямо сообщите, что журнал не обновлён, и подготовьте запись для синхронизации.

Для каждого запроса создавайте отдельную запись до существенной работы; перед итоговым ответом обновляйте результат, решения, проверки, незавершённое и следующий шаг. Сохраняйте чужие записи и используйте свежий SHA при обновлении.

Рабочая инфраструктура: GitHub → GitHub Pages → iPhone/PWA. Сохраняйте существующие lessonId, историю и локальный прогресс. Проверяйте текущий HEAD: приватный traineesimulator на дату 2026-10-29 содержит более старый код.

Указатель сам по себе не подключает другие чаты и не запускает автоматический сбор переписки.
